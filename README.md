# Shrajal Patel – Portfolio Website

A modern, visually immersive personal portfolio built with **Next.js 15**, **React 19**, **TailwindCSS**, and advanced UI animations. Designed to showcase my skills as a **Web Developer, App Developer, and Creative Editor**, this project highlights my journey, projects, resume, skills, and professional background.

---

## 🚀 Features

- Fully responsive, elegant UI  
- Smooth animations & 3D effects  
- Projects, About, Resume, and Contact sections  
- Custom Border Beam animated component (modified)  
- Dark/light mode support  
- Optimized images & structure  
- Fast load times with Next.js 15 + Turbopack

## 🔧 Installation & Setup

### **1. Clone this repository**
```
git clone https://github.com/USERNAME/REPO-NAME.git
cd REPO-NAME
```

### **2. Install dependencies**
```
npm install
```

### **3. Start development server**
```
npm run dev
```

### **4. Build for production**
```
npm run build
```

### **5. Start production server**
```
npm start
```
